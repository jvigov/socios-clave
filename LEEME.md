# Socios Clave: cómo lanzarla con tu propio link

La app abre directo con el link, sin usuario ni contraseña.

## 1. Supabase: crear las tablas
SQL Editor → pega todo el archivo `supabase.sql` → **Run**. Debe salir "Success".

## 2. Supabase: copiar la dirección y la llave
Project Settings → API. Copia la **Project URL** y la clave **anon public**.

## 3. Tu computadora: config.js
Abre `config.js` con el Bloc de notas. Pega la URL y la clave entre las comillas y guarda.

## 4. GitHub
En el repo `socios-clave`, toca **uploading an existing file**. Arrastra los 10 archivos y toca **Commit changes**.

## 5. Vercel
Add New → Project. Importa `socios-clave`, elige Framework **Other** y toca **Deploy**.

## 6. Celular
Abre el link.
- **iPhone:** Compartir → Agregar a inicio.
- **Android:** ⋮ → Instalar app.
